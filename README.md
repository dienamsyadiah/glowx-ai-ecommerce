# GlowX AI E-Commerce

GlowX AI E-Commerce adalah sistem informasi e-commerce berbasis web untuk produk kecantikan. Project ini dilengkapi dengan halaman pengguna, dashboard admin, pengelolaan produk, serta database untuk menyimpan data sistem.

## Fitur Utama
- Halaman pengguna untuk melihat produk
- Dashboard admin
- Pengelolaan data produk
- Pengelolaan data pengguna
- Database produk menggunakan SQL
- Sistem berbasis web untuk kebutuhan e-commerce kecantikan

## Teknologi yang Digunakan
- PHP
- Composer
- MySQL
- HTML
- CSS
- JavaScript

## Struktur Folder
- `dashboard/` : halaman dan fitur untuk admin
- `webUser/` : halaman pengguna/customer
- `psi.sql` : file database project
- `composer.json` : konfigurasi dependency project

## Cara Menjalankan Project
1. Clone repository ini.
2. Import file `psi.sql` ke database MySQL.
3. Jalankan project di server lokal seperti XAMPP.
4. Sesuaikan konfigurasi koneksi database jika diperlukan.
5. Buka project melalui browser.
